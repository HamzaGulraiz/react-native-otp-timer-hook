# React Native OTP Timer

A customizable OTP Timer hook and UI component for React Native that works even when your app is in the background.

## ✨ Features

- Hook: `useOtpTimer` – React-style stateful timer logic
- UI Component: `OtpTimer` – easily pluggable and customizable
- Background-safe: works reliably even when the app goes into background
- Resend logic with count limit
- Easy to style and extend

## 📦 Installation

```bash
npm install react-native-otp-timer
# or
yarn add react-native-otp-timer
